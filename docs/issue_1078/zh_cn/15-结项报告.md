- 与 `thread_mode` 互斥校验、`nb_procs >= 2` 校验、primary lcore 不在 `lcore_list` 校验

## 3. Post-implementation 修复说明

实现完成后在实测中发现了两个回归问题，均已修复：

### 3.1 `primary_slim=0` + `owner_proc_id` 误伤 KNI（文档 12）

- **根因**：commit `1c28aaa2d` 把 KNI 调用条件从 `ff_kni_is_owner_thread()` 改为 `ff_kni_is_runtime_owner()`，但 `primary_slim=0` 时 `owner_proc_id` 生效会导致 primary 不再处理 KNI
- **修复**（`e075e534f`）：门控条件改为 `primary_slim ? ff_kni_is_runtime_owner() : ff_kni_is_owner_thread()`

### 3.2 `primary_slim=1` + KNI 开启时跨进程 TX queue 竞态（文档 13）

- **根因**：primary 执行 KNI process 时 `kni_process_rx` 调 `rte_eth_tx_burst(Port0, queue_id=0)`，但 `primary_slim=1` 时 queue0 归属 secondary worker0，跨进程共享 TX queue 会导致 desc ring 损坏
- **修复**（`f250ad1ea`）：新增 `kni_inject_rp` 共享 ring，primary 的 `kni_process_rx` redirect 到 ring，owner secondary dequeue 后用自己的 `tx_queue_id` 执行 `rte_eth_tx_burst`
- **验证**：ICMP reply 强制走 veth0 测试通过（ping 5/5 0% loss），KNI off 回归通过
