# 02 — 测试结果与数据分析

## 一、Bug 复现结果

### 1.1 基本功能验证（5 条规则）

```
$ tools/sbin/ipfw -P 0 flush
Flushed all rules.

$ tools/sbin/ipfw -P 0 add 100 allow ip from any to any
00100 allow ip from any to any

$ tools/sbin/ipfw -P 0 list
00100 allow ip from any to any
65535 count ip from any to any not // orphaned dynamic states counter
65535 allow ip from any to any
```

**结论**: 少量规则时 ff_ipfw 功能正常。list 输出包含用户规则 + 2 条默认规则（65535 count + 65535 allow）。

### 1.2 二分搜索 breaking point

| 用户规则数 | 总规则数（含默认） | list 结果 | 错误 |
|-----------|----------------|----------|------|
| 100 | 102 | 成功（102 行） | 0 |
| 150 | 152 | 成功（152 行） | 0 |
| 200 | 202 | 成功（202 行） | 0 |
| 250 | 252 | 成功（252 行） | 0 |
| 251 | 253 | 成功（253 行） | 0 |
| **252** | **254** | **失败** | **EINVAL** |
| 260 | 262 | 失败 | EINVAL |
| 300 | 302 | 失败 | EINVAL |
| 500 | 502 | 失败 | EINVAL |

### 1.3 精确 breaking point

**252 条用户规则（+2 默认 = 254 总）** 是精确 breaking point。

### 1.4 失败错误信息

```
$ tools/sbin/ipfw -P 0 list
ipfw: retrieving config failed: Invalid argument
```

"Invalid argument" = EINVAL，来自 `tools/ipfw/compat.c:61` 的 `errno = EINVAL`。

### 1.5 每条规则二进制大小估算

- 缓冲区可用大小 ≈ 10112 字节（MAX_MSG_BUF_SIZE - sizeof(struct ff_msg)）
- 减去开销: sizeof(struct ff_ipfw_args) + sizeof(socklen_t) ≈ 40 字节
- 可用于规则数据: ≈ 10072 字节
- 253 条规则通过，254 条失败
- **每条规则二进制约 39.8 字节**

### 1.6 helloworld 日志检查

复现期间检查 helloworld primary 进程日志，无 EAL 分配错误。EINVAL 失败发生在 secondary 进程（ff_ipfw 工具）侧，primary 进程未收到超限请求。
