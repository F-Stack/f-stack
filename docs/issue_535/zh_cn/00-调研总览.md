# 00 — 调研总览

## Issue #535 详情

- **标题**: Crash on multiple IPFW rules
- **状态**: Open（开放中）
- **创建日期**: 2020-07-28
- **报告者**: chinosat
- **仓库**: F-Stack/f-stack

### 问题描述

使用 f-stack dev 分支 1.21，配置 IPFW 支持，32 worker_processes on 32-core host，13968 huge pages。当 IPFW 规则列表较短时正常工作；当为每个 nginx 进程添加超过 400 条 IPFW 规则时，ipfw 挂起、EAL 分配错误、流量无法处理。

### 环境

- f-stack 版本: dev 分支 1.21
- IPFW 支持: 已启用
- nginx worker_processes: 32
- CPU: 32 核
- Huge Pages: 13968 个（2048 kB/页）

## 代码路径分析

### IPC 消息缓冲区限制

**`lib/ff_msg.h:131`**:
```c
#define MAX_MSG_BUF_SIZE 10240
```
IPC 消息缓冲区上限 10KB。

**`lib/ff_dpdk_if.c:704-709`** — mempool 创建:
```c
message_pool = rte_mempool_create(FF_MSG_POOL,
   MSG_RING_SIZE * 2 * nb_rings,
   MAX_MSG_BUF_SIZE,   // elt_size = 10240
   MSG_RING_SIZE / 2,  // cache_size = 16
   0,
   NULL, NULL, ff_msg_init, NULL,
   socketid, 0);
```

**`lib/ff_dpdk_if.c:688-689`** — `ff_msg_init` 设置可用缓冲区:
```c
msg->buf_addr = (char *)msg + sizeof(struct ff_msg);
msg->buf_len = mp->elt_size - sizeof(struct ff_msg);
```
实际可用缓冲区 ≈ 10240 - sizeof(struct ff_msg) ≈ 10112 字节。

### IPFW 工具的 EINVAL 静默失败

**`tools/ipfw/compat.c:59-64`**（修复前）:
```c
len = sizeof(struct ff_ipfw_args) + *optlen + sizeof(socklen_t);
if (len > msg->buf_len) {
    errno = EINVAL;
    ff_ipc_msg_free(msg);
    return -1;
}
```
当 IPFW 规则总数据超过 ~10KB 时，`getsockopt(IP_FW3)` 获取全部规则的数据超出缓冲区限制，返回 EINVAL 静默失败。

### 已有的动态缓冲区模板

**`tools/compat/sysctl.c:57-69`** — sysctl 工具已实现动态缓冲区方案:
```c
if (total_len > msg->buf_len) {
    extra_buf = rte_malloc(NULL, total_len, 0);
    if (extra_buf == NULL) { errno = ENOMEM; ... return -1; }
    msg->original_buf = msg->buf_addr;
    msg->original_buf_len = msg->buf_len;
    msg->buf_addr = extra_buf;
    msg->buf_len = total_len;
}
```

| 组件 | 位置 | 状态 |

| `original_buf`/`original_buf_len` 字段 | `lib/ff_msg.h:142-143` | 已有 |

## 13.0 Baseline 对比

**`f-stack-13.0-baseline/lib/ff_msg.h:131`**: `#define MAX_MSG_BUF_SIZE 10240` — 与 15.0 相同。

**`f-stack-13.0-baseline/tools/ipfw/compat.c:59-63`**: 同样的 `len > msg->buf_len` → EINVAL 模式。

**结论**: 该 issue 是**长期存在问题**，非 13.0→15.0 升级引入的回归。
