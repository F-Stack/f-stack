### Task 3: 内存泄漏检查 — PASS

| 路径 | 泄漏? | 说明 |
|------|-------|------|
| Path A: 正常完成 | 否 | `ff_ipc_msg_free` 释放动态缓冲区 |
| Path B: send 失败 | 否 | `ff_ipc_msg_free` 释放动态缓冲区 |
| Path C: recv 失败 | 否（既有问题） | msg 已入队由主进程处理，所有工具共享此模式 |
| Path D: malloc 失败 | 否 | `original_buf` 未设置，直接归还 mempool |

**Path C 说明**: `ff_ipc_recv` 失败时不调用 `ff_ipc_msg_free(msg)`，这是**既有设计问题**，存在于 `sysctl.c`、`ioctl.c`、`rtioctl.c`、`libnetgraph/compat.c` 所有工具中，模式完全一致。修复后的 `ipfw/compat.c` 与这些文件保持一致，未引入新问题。
