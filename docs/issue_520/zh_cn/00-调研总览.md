# Issue #520 调研总览

## Issue 信息

| 项目 | 内容 |
|------|------|
| 编号 | #520 |
| 标题 | Disable TX ip checksum offload in VMware ESXi 5.5.0 Update 2 |
| 作者 | vincentmli |
| 创建日期 | 2020-06-10 |
| 状态 | Open |

## 问题描述

VMware ESXi 5.5.0 Update 2 虚拟机中运行 F-Stack Nginx，TX IP checksum offload 默认启用，但虚拟网卡声称支持却实际不计算 IP 校验和，导致发出 IP 包校验和为 0（`bad cksum 0 (->95f6)!`），SYN+ACK 被客户端丢弃，TCP 连接无法建立。同时影响 ICMP ping。

## 调研结论

1. **问题根因**：虚拟化环境（VMware）下虚拟网卡声称支持 TX IP checksum offload 但实际不计算，是环境特定的硬件/虚拟化层问题
2. **已有临时方案**：`tx_csum_offoad_skip=1` 禁用所有 TX checksum offload（IP+L4），但性能损失过大
3. **用户建议**：更细粒度控制，只禁用 IP 层而保留 L4 offload

## 本次修复

### 新增细粒度控制

| 配置项 | 默认值 | 作用 |
|--------|--------|------|
| `tx_csum_ip_skip` | 0 | =1 时只禁用 IP 层 TX checksum offload |
| `tx_csum_l4_skip` | 0 | =1 时只禁用 L4 层 TX checksum offload |

向后兼容：`tx_csum_offoad_skip=1` 仍禁用全部，`=0`（默认）仍启用全部。

### TX 路径守卫修复

发现 TX 路径中 IP checksum offload 缺少 `hw_features.tx_csum_ip` 守卫（L4 路径有 `tx_csum_l4` 守卫），已修复。

## 测试结果

| 测试 | 配置 | TCP 连接 | IP checksum | 结果 |
|------|------|----------|-------------|------|
| T1 | 默认（skip=0） | 成功 | 正确 | PASS |
| T2 | skip=1 | 成功 | 正确 | PASS |
| T3 | ip_skip=1 | 成功 | 正确 | PASS |

## 修改文件

| 文件 | 修改内容 |
|------|----------|
| `lib/ff_config.h` | 新增 `tx_csum_ip_skip` / `tx_csum_l4_skip` 字段 |
| `lib/ff_config.c` | 新增两个配置解析分支 |
| `lib/ff_dpdk_if.c` | 拆分 IP/L4 启用条件 + TX 路径 IP 守卫 + TSO 警告条件 |
| `lib/ff_memory.c` | TX 路径 IP 守卫 |
| `config.ini` | 添加新配置项注释 |
