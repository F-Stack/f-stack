## 测试程序

### Python Echo Server (`example/echo_server.py`)

- 绑定 `0.0.0.0:12373`，接收连接后发送 100 万条时间戳消息
- 每条消息 `str(time.time_ns()) * 200`（约 3800 字节）
- 总数据量约 3.8GB
- 带异常处理（BrokenPipeError/ConnectionResetError）

### Kernel Client (`example/echo_client_kernel.c`)

- 标准 Linux socket + epoll(ET) + recv
- 非 blocking socket，epoll_wait 等待 EPOLLOUT(connect完成) → 发送 GET → 切换 EPOLLIN
- recv buffer 4096，测量首尾延迟差和总耗时
- `-O2` 编译

### F-Stack Client (`example/echo_client_fstack.c`)

- ff_socket/ff_connect/ff_kqueue/ff_kevent/ff_recv
- **使用 kqueue 原生 API** 而非 ff_epoll（因 ff_epoll EPOLLOUT 不稳定）
- 非 blocking socket，kqueue EVFILT_WRITE(connect完成) → 发送 GET → 注销 EVFILT_WRITE
- EVFILT_READ 事件 → ff_recv 循环接收
- `-O2` 编译

## 网络拓扑

```
f-stack-client (<CLIENT_IP>, eth1)
    ↑
    | TCP connect + recv 100万条消息
    |
本机 (双网卡)
  ├── DPDK NIC (<DPDK_NIC_IP>, igb_uio) ← F-Stack client
  └── eth1 (<KERNEL_NIC_IP>, virtio-pci)  ← Kernel client
```

三者在同一 /21 子网（<NETWORK_PREFIX>/21），直连可达。

## F-Stack 配置 (#842 优化配置，用于 T3)

```ini
[dpdk]
lcore_mask=1
idle_sleep=0
pkt_tx_delay=0
port_list=0

[port0]
addr=<DPDK_NIC_IP>
netmask=255.255.248.0
gateway=<GATEWAY_IP>

[freebsd.sysctl]
net.inet.tcp.sendspace=1677721
net.inet.tcp.recvspace=1677721
net.inet.tcp.delayed_ack=0
```
