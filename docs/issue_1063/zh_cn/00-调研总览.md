## UDP Syscall Hook 覆盖验证

通过代码探测确认，F-Stack LD_PRELOAD 模式（`libff_syscall.so`）对 UDP 相关 syscall 的 hook 覆盖完整：

| Hook 函数 | 文件位置 | 验证结果 |
|-----------|----------|----------|
| `fstack_territory()` | `ff_hook_syscall.c:360-374` | L368-369 明确接受 `SOCK_DGRAM` |
| `ff_hook_recvfrom()` | `ff_hook_syscall.c:909-910` | 完整实现，含 `CHECK_FD_OWNERSHIP` 分发 |
| `ff_hook_sendto()` | `ff_hook_syscall.c:1613-1614` | 完整实现，含 `CHECK_FD_OWNERSHIP` 分发 |
| `ff_hook_recvmsg()` | `ff_hook_syscall.c:1429` | 完整实现 |
| `ff_hook_sendmsg()` | `ff_hook_syscall.c:1683` | 完整实现 |
| `ff_hook_epoll_create()` | `ff_hook_syscall.c:1977` | 完整实现 |
| `ff_hook_epoll_ctl()` | `ff_hook_syscall.c:2009` | 完整实现 |
| `ff_hook_epoll_wait()` | `ff_hook_syscall.c:2090` | 完整实现 |

`ff_declare_syscalls.h:18-23` 中 `sendto`、`recvfrom`、`sendmsg`、`recvmsg` 均已声明。

## 结论

F-Stack LD_PRELOAD 模式已完整支持 UDP socket 的所有必要 syscall。新增 UDP 示例无需修改协议栈库代码，只需编写使用标准 POSIX API 的示例程序即可通过 LD_PRELOAD 透明使用 F-Stack 用户态网络栈。
