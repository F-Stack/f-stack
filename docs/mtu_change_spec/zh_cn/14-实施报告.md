for f-stack, executed across milestones M0–M5 per the spec documents in

## Code Changes

### M1: Configuration (`lib/ff_config.h`, `lib/ff_config.c`)
- `enum ff_mbuf_mode` (LARGE/SCATTER)
- `ff_port_cfg.mtu`, `ff_config.dpdk.{mtu_enable,max_mtu,mbuf_mode}`
- Strict `strtoul`-based parsers (`ff_parse_u16`, `ff_parse_mbuf_mode`)
- Cross-field validation: KNI/kernel-coexist exclusion, large data_room overflow
- 8 unit tests (UT-CFG-01..08) + 7 fixtures

### M2: DPDK Layer (`lib/ff_dpdk_if.c`, `lib/ff_memory.h`, `lib/ff_dpdk_if.h`)
- `ff_mtu_data_room_size()` helper (align HEADROOM+max_mtu+L2_overhead)
- `init_mem_pool()`: large mode data_room sizing
- `init_port_start()`: rxmode.mtu + PMD capability check + scatter offload
- `set_mtu`/`get_mtu` readback before port start
- TX paths use `rte_pktmbuf_tailroom()` for single-seg large frames

### M3: ff_veth Integration (`lib/ff_veth.c`, `lib/ff_dpdk_if.h`, `lib/ff_dpdk_if.c`)
- Opaque MTU API: `ff_dpdk_if_get_mtu/set_mtu/get_mtu_capability`
- `ff_dpdk_errno_to_bsd()`: DPDK negative errno → BSD positive errno
- `ff_veth_ioctl(SIOCSIFMTU)`: primary sets hw+sw, secondary sets sw only
- `ff_veth_setup_interface()`: initial if_mtu from hardware

### M4: EBUSY State Machine (`lib/ff_dpdk_if.c`)
- `ff_dpdk_if_set_mtu`: -EBUSY → stop/set_mtu/get_mtu/start
- Failure rollback: restore old_mtu + restart port
- Secondary returns 0 (no hardware operations)
- No IPC transactions/rings/coordinator (per spec constraint)

## Key Design Decisions

1. **No `freebsd/` modifications** (D-MTU-05): `ether_ioctl` ETHERMTU limit
   bypassed by intercepting SIOCSIFMTU in `ff_veth_ioctl`.
2. **Opaque DPDK API**: `ff_veth.c` does not include `rte_ethdev.h`; all
   hardware MTU operations go through `ff_dpdk_if.h` opaque interface.
3. **Secondary process**: Returns 0 from `ff_dpdk_if_set_mtu` (skips
   hardware, caller sets software MTU only).
4. **No cross-process IPC**: Each process sets its own MTU independently;
   primary handles hardware, secondary handles software only.
5. **EBUSY handling**: stop/set/start state machine with rollback, no
   per-port lock (assumes non-concurrent ioctl per "set once per process"
   usage contract).
