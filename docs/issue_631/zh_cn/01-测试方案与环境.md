## 2. 网络拓扑

```
Python UDP sender (f-stack-client <CLIENT_IP>)
    ↓ UDP packets to <DPDK_NIC_IP>:15310
F-Stack UDP receiver (本机 DPDK NIC <DPDK_NIC_IP>)
    - ff_socket(SOCK_DGRAM) → ff_bind(:15310) → FIONBIO
    - loop: ff_recvfrom → count++
    - count==3: ff_shutdown(sockfd, how)
    - continue: check if ff_recvfrom returns 0 or data

内核栈对比测试 (本机 127.0.0.1):
    Python sender → 127.0.0.1:15310
    Kernel UDP receiver (socket/bind/recvfrom/shutdown)
```

## 4. 测试程序

### 4.1 F-Stack UDP shutdown 测试程序

**文件**: `example/udp_shutdown_test.c`

功能:
- 创建 UDP 套接字，绑定到 <DPDK_NIC_IP>:15310
- 设置 FIONBIO 非阻塞模式
- 在 ff_run 循环中调用 ff_recvfrom 接收数据
- 接收 3 个包后调用 ff_shutdown(sockfd, how)
- 继续循环观察后续行为

参数:
- `--how=0|1|2`: shutdown 方式 (SHUT_RD/SHUT_WR/SHUT_RDWR)
- `--connect`: 使用 ff_connect 连接到客户端（测试已连接 UDP 场景）

### 4.2 内核栈 UDP shutdown 对比程序

**文件**: `example/udp_shutdown_test_kernel.c`

功能: 与 F-Stack 版本相同的测试逻辑，使用标准 Linux socket API（socket/bind/recvfrom/shutdown）

### 4.3 Python UDP 发送端

**文件**: `example/udp_sender_631.py`

功能: 以可控间隔发送 UDP 数据包到目标地址

用法: `python3 udp_sender_631.py <target_ip> <port> [count] [interval_ms]`

## 5. 关键技术决策

### 5.1 非阻塞模式选择

使用 `ff_ioctl(sockfd, FIONBIO, &nonblock)` 设置非阻塞模式，而非 `MSG_DONTWAIT` 标志。

原因: Linux `MSG_DONTWAIT`=0x40 (64) 与 FreeBSD `MSG_DONTWAIT`=0x80 (128) 值不一致。F-Stack 的 `ff_recvfrom` 将 flags 直接传给 FreeBSD `kern_recvit`，使用 Linux 值会导致标志被误解。

### 5.2 测试判定逻辑

- **SHUT_RD**: shutdown 后 `recvfrom` 返回 0 (EOF) = PASS；继续收到数据 = FAIL
- **SHUT_WR**: shutdown 后 `sendto` 返回 -1/EPIPE = PASS
- **SHUT_RDWR**: 两者都满足 = PASS
