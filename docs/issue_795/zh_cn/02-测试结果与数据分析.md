## 四、--device 参数测试（错误格式验证）

### 配置
```ini
[dpdk]
extra_eal_args=--device=0000:00:09.0,scalar_enable=1
```

### EAL argv 输出
```
f-stack -c1 -n4 --proc-type=primary --device=0000:00:09.0,scalar_enable=1
```

### DPDK 错误
```
EAL: Invalid 'command line' arguments.
EAL: Error - exiting with code: 1
Error with EAL initialization
```

### 结论
`--device` 不是 DPDK EAL 标准参数，被 EAL 拒绝。这验证了透传机制的正确性（参数确实被追加到 argv），同时确认 DPDK devargs 的正确格式是 `--allow=<bdf>,<devargs>` 或 `-a <bdf>,<devargs>`。

**注意**：此测试证明 extra_eal_args 机制是纯透传，不做参数校验——用户需自行确保参数格式正确（与 DPDK 原生行为一致）。
