# 测试方案与环境

## 一、测试环境

| 项目 | 配置 |
|------|------|
| 服务器 | 物理机 + DPDK 24.11.6 |
| DPDK 网卡 | virtio PCI 0000:00:09.0，IP 9.134.214.176 |
| 客户端 | f-stack-client（ssh 连接），eth1 接口 |
| 测试程序 | `example/csum_test_server`（TCP echo，端口 15200） |
| 客户端脚本 | `example/csum_test_client.py` |
| 配置文件 | `/data/workspace/config.ini`（测试用，不入库） |

## 二、测试矩阵

| 测试 | 配置 | 验证点 | 预期 |
|------|------|--------|------|
| T1 | 默认（无 extra_eal_args） | F-Stack 启动 + EAL argv 不含额外参数 + TCP 连接 | 正常（回归） |
| T2 | `extra_eal_args=--log-level=pmd:8` | EAL argv 含该参数 | 参数透传成功 |
| T3 | `extra_eal_args=--allow=0000:00:09.0,scalar_enable=1` | EAL argv 含该参数 + devargs 透传 + TCP 连接 | 参数透传成功 |

## 三、验证方法

1. **EAL argv 验证**：`dpdk_args_setup()` 中 `printf` 打印最终 argv（`lib/ff_config.c:1303-1305`），检查日志中 `f-stack ...` 行。
2. **TCP 连接验证**：从 f-stack-client 运行 `csum_test_client.py`，验证 echo 回显。
3. **DPDK 初始化验证**：检查 `f-stack-0.log` 中 `Port 0 Link Up` 和 `Successed to register dpdk interface`。

## 四、测试程序

复用 issue #520 的 `csum_test_server.c`（TCP echo 服务器）和 `csum_test_client.py`（TCP 客户端），已验证可工作。

### 启动命令
```bash
cd /data/workspace/f-stack/example
./csum_test_server --conf=/data/workspace/config.ini --proc-type=primary --proc-id=0
```

### 客户端命令（f-stack-client）
```bash
python3 /tmp/csum_test_client.py 9.134.214.176 15200
```

## 五、config.ini 测试值处理

- 测试时在 `/data/workspace/config.ini`（workspace 根目录，非仓库内）添加 `extra_eal_args=xxx`
- 测试完成后用 `sed` 删除该行，恢复默认配置
- 仓库内 `config.ini` 只添加注释（默认注释掉），不含本地测试值
